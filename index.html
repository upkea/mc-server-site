常见问题

服务器是什么版本？

Java 版 1.20 – 1.21.8，纯净生存玩法。

怎么进入服务器？

打开 Minecraft Java 版 1.20 – 1.21.8 → 多人游戏 → 添加服务器 → 填入 play.simpfun.cn:19573 → 加入。详细步骤见上方「如何加入」。

遇到问题或想找管理怎么办？

加入 QQ 群 1107711066，群内可以联系管理、提问交流。

服务器什么时候开服？

服务器长时间在线运行。如果暂时无法进入，可以进群留意开服公告。

页面显示"未检测到开服"，但我能进服？

状态检测用的是海外免费检测节点，对国内服务器偶尔会连不上而误报。判断服务器是否开服，最准的办法是直接进服试试（地址 play.simpfun.cn:19573）：能进去就是开着，页面状态仅供参考。
